## Capture-probability formula (new canonical, full algebra)

```
E[MOIC] = Σ_i [ macro_prob_i × P(capture_i) × MOIC_i + macro_prob_i × (1 − P(capture_i)) × MOIC_sunk ]

where MOIC_sunk = 0.5× (down-round / equity recap if 智元 loses to peer in same macro scenario).
```

Worked example at mid (P(capture) = 0.5 for Bull/Base, 0.6 for Bear-A/B, 1.0 for True Bear):

| Scenario | macro_prob | P(capture) | MOIC_cond | sunk contribution | total |
|---|---|---|---|---|---|
| Bull | 0.35 | 0.5 | 9.0 | 0.35×0.5×0.5 = 0.0875 | 1.575 + 0.0875 = **1.66** |
| Base | 0.35 | 0.5 | 3.8 | 0.35×0.5×0.5 = 0.0875 | 0.665 + 0.0875 = **0.75** |
| Bear-A | 0.125 | 0.6 | 0.77 | 0.125×0.4×0.5 = 0.025 | 0.058 + 0.025 = **0.083** |
| Bear-B | 0.125 | 0.6 | 0.13 | 0.125×0.4×0.5 = 0.025 | 0.010 + 0.025 = **0.035** |
| True Bear | 0.05 | 1.0 | 0.12 | 0 | **0.006** |
| **Total** | | | | | **2.54× (mid)** |

Range: P=0.4 → 2.13×; P=0.6 → 2.95×. Published "2.55× mid, 2.0-3.0× range" ✓.

IRR: 2.54^(1/5) − 1 = 20.5% mid; range 16.3-24.2%. LP real (mid): 20.5% × 0.7 × 0.95 × 0.93 = 12.7%.
