## Limitations explicitly accepted in Round-3

1. **Chart lazy-load full refactor still deferred** (visual-i6 / v2-new-i12). 26 `new Chart()` calls still run synchronously; only `chart-loaded` class is added on intersection. Reasoning: full refactor requires restructuring all chart inits into `const chartInits = {...}` factory, which is a 60-min surgery risking regression. iPad first-paint white-screen 5-10s in low-end devices remains. **Defense**: Round-3 prioritized fixing the 4 fatal + 17 severe / phantom issues; lazy-load is performance optimization not correctness.
2. **SVG `<title>/<desc>` a11y deferred** (visual-i11). Two SVG 不可能三角 still lack ARIA. Same justification.
3. **Table `<caption>` partial** (visual-i9 / v2-new-i11): 10 核心表加了 caption (Comps, DCF, sensitivity, decision-tree second-layer, Risk Register, A.6.1, A.6.2, A.2.1, Returns, 2×2 matrix). Remaining ~18 tables 未加 caption. Trade-off: 10 是核心 IC tables 已满足主要 PE 工作流 (Reader / PDF / LLM); 其余表是 supporting.
4. **N=5 EV IPO median 53× 实际是 [15, 24, 53, 150, 85000] sorted median = 53×, 但 Rivian LTM 85,000× 是 manic artefact** (LTM rev ~$0 → PSR 接近无穷, NTM ~$1.5B 才有意义). 表内已显式说明 footnote A; N=3 (Round-3 主要 anchor 24×) 是更稳健对照.
5. **§6.3 US-led 区间中点 20% vs 新 2×2 matrix US-led 30%** (= 15% + 15%) 之间有 +10pp 差异. Round-3 在 limitation-note 标注; 真正 reconcile 需要重新校准 P(IRA | Tesla Y) 从 50% 降到 ~33% (使 P(Y,Y) = 10%, P(Y,N) = 20%, US-led = 20%). 这是 Round-4 候选 (LBC-3 区间下调或 conditional 重估).
